# 100 часов итальянского B2

Откройте `index.html` в браузере. Установка зависимостей не нужна.

Для локального HTTP-сервера:

```sh
cd /workspace/clock
python3 -m http.server 8000 --bind 127.0.0.1
```

Занятия на курсах учитываются на 50%. Прогресс сохраняется в localStorage текущего браузера; для переноса используйте экспорт и импорт JSON. При смене адреса сайта или браузера потребуется импорт резервной копии.

Для публикации разместите index.html на статическом хостинге, например GitHub Pages. Публикация в этой задаче не выполнялась.
